# ADR-008 Map rendering
**Status: Proposed; tile source Accepted by default (ledger row 50).** maplibre-gl 6.14.0 + react-map-gl 8.1.3; **OpenFreeMap vector tiles**, style `positron` with DESIGN-DIRECTION §5.1 overrides; style URL in the single env var `NEXT_PUBLIC_MAP_TILE_URL` (default `https://tiles.openfreemap.org/styles/positron`); no key, no cookies. Attribution "© OpenFreeMap © OpenMapTiles © OpenStreetMap contributors" always visible (MapLibre compact control). No bulk prefetch (ToS offline limit 3,000 tiles/50 MB, ≤4 parallel). No SLA: fallback is self-hosting OpenFreeMap or another vector source behind the same env var. Evidence: https://openfreemap.org/ , https://openfreemap.org/tos/ , https://www.openstreetmap.org/copyright (read 2026-10-14). Supersedes the earlier OSM raster / `NEXT_PUBLIC_TILE_URL` wording.
